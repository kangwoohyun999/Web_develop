기본 구조 태그
* <!DOCTYPE html>: HTML5 문서임을 명시
* <html>, <head>, <title>, <body>: 웹 페이지의 기본 골격을 구성하는 필수 태그

속성이 중요한 주요 태그
* 이미지 (<img>): src (파일 경로), width/height (크기), alt (이미지 설명).
* 하이퍼링크 (<a>): href (연결할 주소), target (링크를 열 창의 위치).
* 입력 양식 (<input>): type (text, password, email, checkbox 등), placeholder (입력 힌트), value (초기값).
* 멀티미디어 (<audio>, <video>): src, controls (재생 막대 표시), autoplay (자동 재생), loop (반복 재생).

문서 구조화 (시맨틱 태그)
* <header>, <nav>, <section>, <article>, <aside>, <footer>: 문서의 구조와 의미를 전달하기 위해 사용합니다.

CSS 스타일 속성
* color: 글자 색상.
* font-size: 글자 크기 (px, %, auto 등 사용 가능).
* font-weight: 글자 굵기 (예: bold).
* text-decoration: 텍스트 꾸밈 (예: none, underline).
* text-shadow: 텍스트에 그림자 효과를 줍니다.

박스 모델
* width, height: 요소의 폭과 높이
* margin: 테두리 바깥쪽의 여백
* padding: 테두리와 콘텐츠 사이의 안쪽 여백
* border: 테두리 두께, 모양, 색상 (예: 5px solid yellowgreen)
* box-shadow: 박스에 그림자 효과를 추가합니다

배경 및 외관
* background-color: 배경 색상.
* background-image: 배경에 사용할 이미지.
* visibility: 요소를 보이게 하거나 숨깁니다 (visible, hidden).

배치 및 레이아웃
* display: 요소의 출력 방식 (block, inline, inline-block, none).
* top, bottom, left, right: 위치 지정 속성.
* float: 요소를 왼쪽이나 오른쪽으로 떠 있게 배치합니다.
* z-index: 요소들이 겹칠 때의 수직 쌓임 순서를 결정합니다.
* flexbox, grid: 현대적인 웹 레이아웃을 구성하는 고급 기능입니다.
  <flexbox>
  예시 1: 수평 정렬과 간격 (justify-content)
  * 메뉴 바처럼 요소들을 가로로 나열하고 사이 간격을 일정하게 벌릴 때 사용합니다.
  * 코드 예: .container { display: flex; justify-content: space-between; }
  예시 2: 정중앙 배치 (align-items)
  * 부모 박스의 한가운데에 자식 요소를 수직/수평 모두 중앙에 맞출 때 유용합니다.
  * 코드 예: .container { display: flex; justify-content: center; align-items: center; }
