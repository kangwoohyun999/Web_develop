🚨 시험 직전 반드시 확인

  • body { font-size: 15px; } — 기본 폰트 꼭 설정
  • a { text-decoration: none; } — 링크 밑줄 제거 꼭 설정
  • table { border-collapse: collapse; } — 표 쓸 때 꼭 설정
  • ul { list-style: none; } — 목록 마커 제거
  • float 쓰면 반드시 footer { clear: both; } 또는 overflow: hidden
  • iframe 연결: a의 target 값 = iframe의 name 값 일치시키기
  • 앵커 이동: href="#아이디" ↔ id="아이디" 짝 맞추기
  • position: absolute 쓰면 부모에 position: relative 꼭 설정
  • 학번을 id 또는 class 이름으로 사용 (예: id="202001234")
  • 이미지는 img/ 또는 image/ 폴더에 저장, 경로 정확히
  • 외부 CSS 파일: <link rel="stylesheet" href="style.css">
  • 코딩 스타일: 블록별 주석, html↔css 순서 일치, tab 들여쓰기
