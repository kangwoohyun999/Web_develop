# 웹개발기초 기말고사 대비 정리

> **출제 방식:** HTML·CSS 코드는 제공 → **JavaScript / jQuery 부분만 직접 작성**
> **문제 구성:** JS 1문제 + jQuery 1문제 (Open-book, 90분)
> **핵심 패턴:** 폼 값 읽기(라디오·체크박스·텍스트상자) + DOM 동적 추가/삭제

---

## 1. 시험 출제 포인트

| 기능 | JavaScript | jQuery | 강의 출처 |
|------|-----------|--------|-----------|
| 텍스트 상자 값 읽기 | `.value` | `.val()` | 예제 9-9 |
| 라디오 버튼 값 읽기 | `querySelectorAll` + `r.checked` | `$("input[name]:checked").val()` | 예제 9-17 / jq22 |
| 체크박스 순회 | `forEach` + `cb.checked` | `.each()` + `this.checked` | 예제 9-18 / jq23 |
| 콘텐츠 변경 | `.textContent` / `.innerHTML` | `.text()` / `.html()` | 예제 8-3, 9-11 |
| 동적 태그 추가 | `createElement` + `appendChild` | `$("<li>")` + `.append()` | 예제 8-10 / 14주차 p.33 |
| 동적 태그 삭제 | `.innerHTML = ""` | `.empty()` | 14주차 p.35 |
| 보이기 / 숨기기 | `.style.display` | `.show()` / `.hide()` | 13주차 p.27 |
| 숫자 검증 | `isNaN()` + 음수 체크 | 동일 | 예제 6-4 |

## 2. JavaScript 핵심 패턴

### 2-1. 폼 요소 값 읽기

```javascript
// ① 텍스트 상자
var val = document.getElementById("amount").value;

// ② 라디오 버튼 — 선택된 값 읽기
var radios = document.querySelectorAll("input[name='action']");
var action = "";
for (var r of radios) {
  if (r.checked) { action = r.value; break; }
}

// ③ 체크박스 — 전체 순회하며 체크 여부 확인
var cbs = document.querySelectorAll("input[name='item']");
cbs.forEach(function(cb) {
  if (cb.checked) {
    var price = parseInt(cb.value);
    var name  = cb.dataset.name;   // data-name 속성
  }
});

// ④ 콤보박스 (select)
var sel  = document.getElementById("mySelect");
var val  = sel.value;                            // 선택된 value
var text = sel.options[sel.selectedIndex].text;  // 선택된 텍스트
```

### 2-2. DOM 조작

```javascript
// 내용 변경
document.getElementById("msg").textContent = "처리 완료";
document.getElementById("msg").innerHTML   = "<b>굵게</b>";

// 입력 상자에 값 쓰기
document.getElementById("outBalance").value = balance;

// 보이기 / 숨기기
document.getElementById("payArea").style.display = "none";   // 숨기기
document.getElementById("payArea").style.display = "block";  // 보이기

// 동적 태그 추가 — li 안에 span 2개 (장바구니 패턴)
var li  = document.createElement("li");
var sp1 = document.createElement("span");
var sp2 = document.createElement("span");
sp1.textContent = "키보드";
sp2.textContent = "20,000원";
li.appendChild(sp1);
li.appendChild(sp2);
document.getElementById("cartList").appendChild(li);

// 자식 요소 전체 삭제
document.getElementById("cartList").innerHTML = "";
```

### 2-3. 이벤트 리스너 등록 (3가지 방법)

```javascript
// 방법 1 — HTML 태그 속성 직접 (onclick=)
// <button onclick="run()">실행</button>

// 방법 2 — 이벤트 리스너 프로퍼티
document.getElementById("btnRun").onclick = function() { run(); };

// 방법 3 — addEventListener (권장)
document.getElementById("btnRun").addEventListener("click", function() { run(); });
```

### 2-4. 숫자 검증 (단골 패턴)

```javascript
var amt = parseFloat(document.getElementById("amount").value);
if (isNaN(amt) || amt < 0) {
  document.getElementById("msg").textContent = "금액 오류";
  return;   // 함수 중단
}
```

### 2-5. 메시지 배열 (은행 문제 패턴)


## 3. jQuery 핵심 패턴

### 3-1. 기본 구조 (시험 템플릿)

```html
<!-- head 안에 CDN 삽입 -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<!-- CSS도 내부에 (외부 파일 X) -->
<style>
  /* ... */
</style>

<!-- body 맨 아래 또는 head 안 script -->
<script>
$(function () {        // $(document).ready 축약형
  // 여기에 코드 작성
});
</script>
```

### 3-2. 값 읽기 / 쓰기

```javascript
// 텍스트 상자 읽기 / 쓰기
$("#amount").val()           // 읽기
$("#outBalance").val(10000)  // 쓰기

// span, div 텍스트 읽기 / 쓰기
$("#msg").text()             // 읽기
$("#msg").text("완료")       // 쓰기

// HTML 쓰기
$("#msg").html("<b>굵게</b>")

// 속성 읽기 / 쓰기
$("img").attr("src")                // 읽기
$("img").attr("src", "new.png")     // 쓰기

// 상태(prop) 읽기 / 쓰기
$(this).prop("checked")             // true/false 읽기
$("input[name='pay']").prop("checked", false)  // 체크 해제
```

### 3-3. 폼 요소 값 읽기 ★★★ (시험 핵심)

```javascript
// ① 라디오 버튼 — 선택된 값 읽기 (jq22 패턴)
var action = $("input[name='action']:checked").val();

// ② 체크박스 — 체크된 것만 순회 (jq23 패턴, 권장)
$("input[name='item']:checked").each(function () {
  var price = parseInt($(this).val());
  var name  = $(this).data("name");   // data-name 속성
});

// ③ 체크박스 — 전체 순회하며 this.checked 확인
$("input[name='item']").each(function () {
  if (this.checked) {
    var price = parseInt(this.value);
  }
});

// ④ 체크된 항목 개수 확인
if ($("input[name='item']:checked").length === 0) {
  alert("상품을 선택하세요.");
}

// ⑤ 콤보박스
var v = $("#mySelect option:selected").val();
var t = $("#mySelect option:selected").text();
```

### 3-4. 이벤트 등록

```javascript
// 클릭
$("#btnRun").on("click", function () { });
$("#btnRun").click(function () { });      // 단축형

  var sel = $(this).val();  // 방금 변경된 라디오 값

// 폼 전체에서 change 감지
$("#myForm").on("change", function () {
  var sel = $("input[name='action']:checked").val();
});
```

### 3-6. 동적 태그 추가 / 삭제 ★★★ (14주차 핵심)

```javascript
// append: 부모 요소 끝에 자식 추가
$("ul").append("<li>새 항목</li>");

// li 안에 span 2개 추가 (장바구니 문제 Hint 패턴)

// empty: 자식 요소 전체 삭제 (태그 자신은 유지)

$("#myDiv").remove();
```

## 4. 연습문제 — jQuery 구현 코드

> **시험 조건:** HTML·CSS는 이미 주어진다. `<script>` 블록 안의 jQuery 코드만 작성.

---

### 4-1. 은행 계좌 시뮬레이션 (3-2번)

**화면 구조 (주어지는 HTML)**
```
[ ● 잔액 확인  ○ 저금  ○ 인출  ○ 이자 지급 ]  [실행]
┌──────────────┬──────────┬──┬──────┬──────────┬──┐
│ 저금/인출 금액 │ [input]  │원│ 잔액 │ [input]  │원│
├──────────────┼──────────┼──┼──────┼──────────┼──┤
│ 이율          │   2%     │  │ 이자 │ [input]  │원│
└──────────────┴──────────┴──┴──────┴──────────┴──┘
처리 메시지: <span id="msg">
```

**주요 HTML id (시험에서 주어지는 것들)**
- 라디오: `name="action"` / value: `"check"`, `"save"`, `"withdraw"`, `"interest"`
- 저금/인출 금액 입력: `id="amount"`
- 잔액 출력: `id="outBalance"`
- 이자 출력: `id="outInterest"`
- 실행 버튼: `id="btnRun"`
- 메시지: `id="msg"`

**작성할 jQuery 코드**
```javascript
$(function () {

  var balance = 10000;  // 초기 잔액
  var rate    = 0.02;   // 이율 2%

  /* 처리 메시지 배열 (문제 명세 그대로) */
  var MSG = [
    "잔액 확인 완료",       // 0
    "저금 완료",            // 1
    "인출 완료",            // 2
    "이자 지급 완료",       // 3
    "저금 금액 오류",       // 4
    "인출 금액 오류",       // 5
    "인출 불가(잔액 부족)"  // 6
  ];

  /* [실행] 버튼 클릭 */
  $("#btnRun").on("click", function () {

    var action = $("input[name='action']:checked").val();  // ← 라디오 읽기 (jq22)
    var amt    = parseFloat($("#amount").val());

    $("#msg").text("");
    $("#outInterest").val("");

    if (action === "check") {
      $("#outBalance").val(balance);
      $("#msg").text(MSG[0]);

    } else if (action === "save") {
      if (isNaN(amt) || amt < 0) { $("#msg").text(MSG[4]); return; }
      balance += amt;
      $("#outBalance").val(balance);
      $("#msg").text(MSG[1]);

    } else if (action === "withdraw") {
      if (isNaN(amt) || amt < 0) { $("#msg").text(MSG[5]); return; }
      if (amt > balance)          { $("#msg").text(MSG[6]); return; }
      balance -= amt;
      $("#outBalance").val(balance);
      $("#msg").text(MSG[2]);

    } else if (action === "interest") {
      var interest = balance * rate;
      balance += interest;
      $("#outInterest").val(interest);
      $("#outBalance").val(balance);
      $("#msg").text(MSG[3]);
    }
  });

});
```

### 4-2. 장바구니 시뮬레이션 (14-2번)

**화면 구조 (주어지는 HTML)**
```
쇼핑 장바구니
─────────────────────────────────────────────
□ 키보드 (20,000원)  □ 마우스 (10,000원)  □ 모니터 (150,000원)
[추가]  [구매]

┌── 결재 수단 선택 (display:none) ──────────┐
│ ○ 신용카드  ○ 계좌이체  ○ 카카오페이       │
│ [구매 진행]  [취소]                        │
└───────────────────────────────────────────┘

상품명                        금액
──────────────────────────────────
(여기에 li 동적 추가됨)

합계: [ 0 ] 원
처리 메시지:
```

**주요 HTML id (시험에서 주어지는 것들)**
- 체크박스: `name="item"` / value: 가격, `data-name`: 상품명
- 추가 버튼: `id="btnAdd"` / 구매 버튼: `id="btnBuy"`
- 결재 수단 영역: `id="payArea"` (초기 `display:none`)
- 결재 수단 라디오: `name="pay"`
- 구매 진행: `id="btnPayGo"` / 취소: `id="btnCancel"`
- 장바구니 목록: `id="cartList"` (`<ul>`)
- 합계 입력: `id="totalInput"`
- 메시지: `id="msgArea"`

**작성할 jQuery 코드**
```javascript
$(function () {

  var total = 0;

  /* ① [추가] 버튼: 체크된 상품 → li 동적 추가 */
  $("#btnAdd").on("click", function () {

    var checked = $("input[name='item']:checked");   // ← 체크박스 읽기 (jq23)
    if (checked.length === 0) {
      alert("상품을 선택한 후 추가 버튼을 클릭하세요.");
      return;
    }

    checked.each(function () {
      var name  = $(this).data("name");
      var price = parseInt($(this).val());

      /* li 태그 내부에 span 2개 (문제 Hint) */
      var $li = $("<li>");
      $li.append($("<span>").text(name));
      $li.append($("<span>").text(price.toLocaleString() + "원"));
      $("#cartList").append($li);    // ← 동적 추가 (14주차 p.33 append)

      total += price;
      $(this).prop("checked", false);
    });

    $("#totalInput").val(total.toLocaleString());
  });

  /* ② [구매] 버튼: 장바구니 비었으면 오류 / 결재 수단 show */
  $("#btnBuy").on("click", function () {
    if ($("#cartList li").length === 0) {
      alert("상품을 추가한 후 구매 버튼을 클릭하세요.");
      return;
    }
    $("#payArea").show();    // ← 결재 수단 보이기 (13주차 p.27 show)
  });

  /* ③ [구매 진행] 버튼: confirm → 완료 후 empty 초기화 */
  $("#btnPayGo").on("click", function () {
    var pay = $("input[name='pay']:checked").val();   // ← 라디오 읽기 (jq22)
    if (!pay) { alert("결재 수단을 선택하세요."); return; }

    var ok = confirm(pay + "(으)로 결재하시겠습니까?");
    if (ok) {
      $("#payArea").hide();
      $("input[name='pay']").prop("checked", false);
      $("#cartList").empty();       // ← 장바구니 초기화 (14주차 p.35 empty)
      total = 0;
      $("#totalInput").val("0");
      $("#msgArea").text("처리 메시지: 결재가 완료되었습니다.");
    }
  });

  /* ④ [취소] 버튼: 결재 수단 숨기기 */
  $("#btnCancel").on("click", function () {
    $("#payArea").hide();    // ← 결재 수단 숨기기 (13주차 p.27 hide)
    $("input[name='pay']").prop("checked", false);
  });

});
```

## 5. JavaScript ↔ jQuery 대조표

| 기능 | JavaScript | jQuery |
|------|-----------|--------|
| 요소 선택 | `document.getElementById("id")` | `$("#id")` |
| 텍스트 읽기 | `el.textContent` | `$("#id").text()` |
| 텍스트 쓰기 | `el.textContent = "값"` | `$("#id").text("값")` |
| input 값 읽기 | `el.value` | `$("#id").val()` |
| input 값 쓰기 | `el.value = "값"` | `$("#id").val("값")` |
| 라디오 값 읽기 | `for r of radios: if(r.checked)` | `$("input[name]:checked").val()` |
| 체크박스 순회 | `cbs.forEach(cb => if cb.checked)` | `$("input:checked").each(fn)` |
| 숨기기 | `el.style.display = "none"` | `$("#id").hide()` |
| 보이기 | `el.style.display = "block"` | `$("#id").show()` |
| 태그 생성 | `document.createElement("li")` | `$("<li>")` |
| 자식 추가 | `parent.appendChild(child)` | `$("ul").append($li)` |
| 자식 전체 삭제 | `el.innerHTML = ""` | `$("ul").empty()` |
| 이벤트 등록 | `el.addEventListener("click", fn)` | `$("#id").on("click", fn)` |

## 6. 시험 직전 체크리스트

**공통**
- [ ] `<script src="jquery CDN">` 를 `<head>` 또는 `<body>` 안에 삽입했는가
- [ ] 모든 jQuery 코드를 `$(function () { ... });` 안에 작성했는가
- [ ] CSS와 jQuery를 **html 파일 내부**에 작성했는가 (외부 파일 금지)

**은행 계좌 문제**
- [ ] 라디오 값: `$("input[name='action']:checked").val()` 으로 읽었는가
- [ ] 처리 메시지를 **배열**에 저장하고 인덱스로 참조했는가
- [ ] 저금/인출 금액 `isNaN()` + 음수 검증을 했는가
- [ ] 인출 시 잔액 부족 검증(`amt > balance`)을 했는가
- [ ] 이자 지급 시 이율 2% 적용 후 잔액과 이자를 모두 출력했는가

**장바구니 문제**
- [ ] 체크박스: `$("input[name='item']:checked").each(fn)` 으로 순회했는가
- [ ] 장바구니 항목: `$("<li>")` + `$("<span>")` 2개 + `.append()` 패턴인가
