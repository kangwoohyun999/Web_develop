## ② 폼 요소 값 읽기

```javascript
/* 텍스트 상자 */
var val = $("#id").val();                          // 읽기
$("#id").val("새값");                              // 쓰기

/* 라디오 — 선택된 값 (jq22) */
var sel = $("input[name='action']:checked").val();

/* 체크박스 — 체크된 것만 순회 (jq23) */
$("input[name='item']:checked").each(function () {
  var price = parseInt($(this).val());
  var name  = $(this).data("name");               // data-name 속성
});

/* 체크박스 — 전체 순회 */
$("input[name='item']").each(function () {
  if (this.checked) { var v = this.value; }
});

/* 체크박스 개수 확인 */
if ($("input[name='item']:checked").length === 0) { alert("선택!"); }

/* 콤보박스 (select) */
var v = $("#sel option:selected").val();
var t = $("#sel option:selected").text();
$("#sel").on("change", function () { var v = $(this).val(); });

/* 체크박스 상태 확인 */
var ok = $("#agree").is(":checked");               // true / false
$("#agree").prop("checked", false);               // 체크 해제
```

## ⑤ 동적 태그 추가 / 삭제 ★ (14주차 p.33, p.35)

```javascript
/* 문자열로 바로 추가 */
$("ul").append("<li>새 항목</li>");
$("ul").prepend("<li>맨 앞 항목</li>");

/* 객체로 추가 — li 안에 span 2개 (장바구니 Hint 패턴) */
var $li = $("<li>");
$li.append($("<span>").text("상품명"));
$li.append($("<span>").text("10,000원"));
$("#cartList").append($li);

/* 삭제 */
$("#cartList").empty();    // 자식 전체 삭제 (태그 유지)
$("#myDiv").remove();      // 태그 자체 삭제
$("li").last().remove();   // 마지막 li 삭제
```

## ⑥ 이벤트

```javascript
$("#btn").on("click", function () { });           // 클릭
$("#btn").click(function () { });                 // 단축형
$("#sel").on("change", function () { });          // 변경
$("#inp").on("focus", function () {               // 포커스
  $(this).css("background", "lightyellow");
});
$("#inp").on("blur", function () {                // 포커스 해제
  if ($(this).val() === "") { alert("입력하세요"); $(this).focus(); }
});
$("#inp").on("input", function () { });           // 입력 즉시 (oninput)
```

## ⑫ 기출문제별 핵심 패턴 요약

| 연도 | 문제 | JS 핵심 | jQuery 핵심 |
|------|------|---------|-------------|
| 2021-2 | 계산기 | `input.value` 읽기/쓰기, `eval()` or 직접 계산 | `.val()` 읽기/쓰기 |
| 2021-2 | 회원 폼 | 라디오 `querySelectorAll` + `r.checked`, `select.value` | `$(...:checked).val()`, `.val()` |
| 2022-1 | 은행 계좌 | 라디오 읽기, 배열 MSG[], isNaN 검증 | `$(...:checked).val()`, MSG[] |
| 2022-1 | 성적처리 | 라디오, 배열, toFixed(1), 함수 분리 | `$(...:checked).val()`, `.text()` |
| 2023-1 | 상품 콤보+장바구니 | `onchange`, `createElement`+`appendChild` | `.on("change")`, `.append()` |
| 2023-1 | 랜덤 이미지 | `setInterval`, `Math.random()`, 이미지 배열 | `setInterval`, `.attr("src")` |
| 2023-1 | 로드맵(앞/뒤 추가) | `prepend`/`append`, `removeChild`, `focus` | `.prepend()`, `.append()`, `.remove()` |
| 2023-1 | 행정구역 조회 | 라디오, 체크박스, 배열 오류메시지 | `$(...:checked).val()`, `.is(":checked")` |
| 2024-1 | 환율 계산 | `oninput`, 배열(나라/코드/단위/환율) | `.on("input")`, 배열 인덱스 |
| 2024-1 | 신청양식 | `date input`, `select`(시/분), `disabled`, `focus` | `.prop("disabled")`, `.val()` |
| 2024-1 | ID찾기 | `setInterval` 카운트다운, 랜덤 4자리 | `.on("click")`, `setInterval` |
| 2025-1 | 장바구니 | 체크박스, `createElement`+span2개, show/hide | `.each()`, `.append()`, `.show()/.hide()` |
| 2025-1 | To-do List | 라디오+콤보, `append`/`remove`, show/hide | `jq21`+`jq22`, `.append()`, `.remove()` |

## ⑮ 자주 쓰는 메서드 한눈에 보기

| 메서드 | 기능 |
|--------|------|
| `.val()` | input 값 읽기/쓰기 |
| `.text()` | 텍스트 읽기/쓰기 |
| `.html()` | HTML 읽기/쓰기 |
| `.attr("src","...")` | 속성 변경 |
| `.prop("checked",false)` | 상태 변경 |
| `.css("color","red")` | 스타일 변경 |
| `.show()` / `.hide()` | 보이기/숨기기 |
| `.append($li)` | 자식 끝에 추가 |
| `.prepend(...)` | 자식 앞에 추가 |
| `.empty()` | 자식 전체 삭제 |
| `.remove()` | 태그 자체 삭제 |
| `.each(fn)` | 반복 순회 |
| `.length` | 선택 개수 |
| `.is(":checked")` | 체크 여부 |
| `.data("name")` | data-* 속성 |
| `.on("click",fn)` | 이벤트 등록 |
| `.focus()` | 포커스 주기 |
| `$.on("change",fn)` | select/radio 변경 |
